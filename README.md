# BATTLESHIP

«Морський бій» — це гра для двох гравців, у якій кожен гравець має власне ігрове поле з розташованими на ньому кораблями. Гравці по черзі виконують ходи, намагаючись влучити в кораблі суперника, називаючи координати клітин. Якщо постріл влучає в корабель, гравець отримує право зробити ще один хід. Метою гри с першим знищити всі кораблі суперника.
