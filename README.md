🚢 Морський бій (Paper Style Battleship)

Гра "Морський бій", реалізована на Python + Pygame у стилі намальованого зошита ✏️📄

🎮 Основні можливості
🎯 Режим для 2 гравців
🧠 Ручна та автоматична розстановка кораблів
👁️ Приховане поле суперника
💥 Логіка попадань, промахів і знищення кораблів
🏆 Екран перемоги
🎨 Унікальний paper-style дизайн
🖼️ Кастомні assets (кораблі, маркери)
🔊 Саунд-дизайн (паперовий стиль)
🕹️ Управління
Розстановка кораблів
ЛКМ — поставити корабель
ЛКМ по кораблю — перемістити
ПКМ — видалити корабель
R — змінити напрямок
Бій
ЛКМ по полю суперника — зробити постріл

⚙️ Встановлення
1. Встанови Python (3.10+)
2. Встанови залежності
pip install pygame numpy
▶️ Запуск гри
python main.py
🔊 Генерація звуків
python generate_sounds.py

Після цього всі звуки з’являться в:

assets/sounds/

🧠 Логіка гри
Кораблі не можуть торкатися навіть по діагоналі
При знищенні корабля:
всі клітинки навколо автоматично позначаються як "мимо"
При попаданні гравець ходить ще раз
При промаху — передача ходу
🏆 Перемога

Гравець перемагає, коли:

всі клітинки кораблів суперника знищені
